Verdict: needs-attention

Do not ship yet: reference switching reuses segment identities, follow mode misses newly enrolled tracks, and rendition eviction can invalidate advertised segments. Static review against the existing origin/main; sandbox restrictions prevented fetching or running tests. No concrete pruning/recovery defect established.

Findings:
- [high] Reference switching reuses existing segment URLs (rs/moq-hls/src/export/rendition.rs:401-405)
  Segment numbers come directly from the reference track's independent sequence. watch_catalog switches references and clears rows without changing the URL generation. Reproduce: serve video B through sequence 100, then add alphabetically earlier video A whose timeline starts at 0. Surviving rendition playlists rewind and reuse seg/0.m4s for different content; existing cursors skip entries until their previous sequence is exceeded. The prior switching finding remains real.
  Recommendation: Assign broadcast-wide monotonic segment identities across reference changes, or explicitly replace the URL namespace and rendition cursors when switching. Test switching between independently numbered timelines.
- [high] Follow mode permanently excludes tracks enrolled after startup (rs/moq-cli/src/archive.rs:101-108)
  Import lists timelines once, then only refreshes the Reader's fixed timeline vector. serve() also captures a fixed list of accepted media tracks. Reproduce: start import --follow with audio recorded, then enroll video in the running export. Repeated refreshes never publish video's timeline, and requests for video are rejected as NotFound despite committed objects. The prior enrollment finding remains real.
  Recommendation: Discover new timelines during follow refreshes and enroll them into both timeline replay and the shared served-track registry. Add a late-track enrollment integration test.
- [high] Independent span eviction changes still-advertised segment content (rs/moq-hls/src/export/spans.rs:103-105)
  Spans evicts against its own newest timestamp, while playlist rows expire against the reference timeline. Reproduce with a 30-second window: pause the reference at 40 seconds while another rendition advances to 80 seconds. That rendition removes records covering the reference's still-listed 10–40 second segments, so previously resolvable segment URLs become gaps. Even ordinary watcher skew can expose this disagreement. The prior eviction finding remains real.
  Recommendation: Coordinate span retention with the oldest advertised reference boundary, including snapping tolerance. Handle source pops explicitly so unavailable content is not silently substituted for an already advertised segment. Test a stalled reference with an advancing sibling.
- [medium] Duplicate enrollment resets state still owned by another recorder (rs/moq-mux/src/timeline.rs:507-516)
  Timelines::track accepts an already-active name, replaces its segmenter, and returns another Recorder sharing the same Live. Reproduce: retain recorder A, enroll B under the same name, report group 10 through A and group 0 through B. B's report closes the shared timeline on a position error. Dropping A can also flush B's open record. Move-only Recorder does not enforce exclusive ownership here.
  Recommendation: Reject enrollment while a recorder owns the name. Require continuing media positions for subsequent enrollment, or a fresh track name when group numbering restarts. Test overlapping recorder lifetimes.
