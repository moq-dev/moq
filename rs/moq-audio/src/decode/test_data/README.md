# Native audio reference vectors

These short encoded inputs and little-endian interleaved `f32` references exercise
AAC-LC mono/stereo at 44.1/48 kHz, Opus pre-skip, real speech, stepped frequencies,
and family-one 5.1 channel order. Tests compare every sample and the exact sample
count against FFmpeg's independent native AAC/Opus decoders. Tests need no FFmpeg
installation or network. Every compiled backend participates; currently those are
Symphonia AAC and the Rust libopus port, with no platform-specific backend.

## Recording and license

The speech is Neil Armstrong's July 20, 1969 NASA Apollo 11 recording, cropped to
10.0–10.4 seconds. NASA created the recording; it is in the public domain in the
United States. Credit: NASA / Neil Armstrong.

- [NASA's original recording source](http://science.ksc.nasa.gov/history/apollo/apollo-11/sounds/a11step.wav), as identified by the archive below.
- [Wikimedia source and NASA public-domain notice](https://commons.wikimedia.org/wiki/File:Neil_Armstrong_small_step.wav).
- [NASA media usage guidelines](https://www.nasa.gov/nasa-brand-center/images-and-media/).
- [Archived WAV](https://upload.wikimedia.org/wikipedia/commons/b/bb/Neil_Armstrong_small_step.wav), SHA-256 `9c2146638c3acba0c05643d18ee3a03fd2d5c167f89cf160579f97266b368cd2`.

Synthetic tone vectors are generated by this repository's `generate.py`.
The existing mux `bbb.mp4` remains untouched: its first two AAC access units are
silence and its third points into MP4 metadata, so it cannot supply a real decoded
waveform reference.

## Reproduction

Generated with FFmpeg 9.0.2 from the repository's Nix dev shell:

```sh
curl --fail --location https://upload.wikimedia.org/wikipedia/commons/b/bb/Neil_Armstrong_small_step.wav --output .tmp/apollo11.wav
nix develop --command python3 rs/moq-audio/src/decode/test_data/generate.py .tmp/apollo11.wav
```

The script checks the source hash and contains every encode/decode argument.
Its input-side `-c:a aac` / `-c:a opus` selects FFmpeg's native decoders explicitly.
The Opus encoder is libopus, independent of the native reference decoder.
CMAF uses an empty movie header and one sample per fragment with a default movie
fragment base. Surround uses MPEG-TS because current CMAF ingest refuses Opus
channel mapping family one. Its TS path declares no pre-skip; the reference does
the same. This tests the supported ingest without expanding the container API.

## Alignment and measured error

Reference PCM includes all decoded AAC padding and excludes the Opus `dOps`
pre-skip. Backend tests remove exactly the backend's declared delay. Consumer
tests decode from each track's first packet, which trims no warmup, so they
compare against the whole reference. No correlation search, gain fitting, channel permutation,
or per-run tolerance adjustment is allowed.

The following maxima were measured on x86-64 Linux with the pinned Nix toolchain,
across fresh backends and their consumer path. Bounds are the next binary power
above each codec family's largest observed difference. Full waveform comparison
therefore checks frequency, gain, channel ordering and packet history together.

| Family | Maximum RMS error | Maximum peak error | RMS bound | Peak bound |
| --- | ---: | ---: | ---: | ---: |
| AAC (speech and stereo tones, both rates) | 4.933e-8 | 5.868e-7 | 2^-24 | 2^-20 |
| Opus mono speech | 1.404e-8 | 8.941e-8 | 2^-26 | 2^-23 |
| Opus 5.1 tones | 9.072e-5 | 2.348e-3 | 2^-13 | 2^-8 |

AAC perceptual noise substitution (PNS) synthesizes noise with a pseudo-random
state. Symphonia's fresh decoder and FFmpeg start with the same seed, but
Symphonia intentionally retains that generator state across reset while clearing
overlap/prediction state. A replay after reset need not reproduce the same noise
waveform. These independent-reference comparisons use fresh decoders instead of
mistaking valid PNS noise for a decoding failure. Resampler partition, drain and
reset invariants are tested separately with deterministic PCM.
