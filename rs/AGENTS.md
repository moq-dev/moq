The `/rs` Cargo workspace.

# Crates

- A crate does one thing. Component crates are `moq-<component>` (`hang` is the exception); binaries never carry a `-cli` suffix.
- `kio` provides the async primitives everything polls through.
- `moq-quic` (our quinn fork) is the only QUIC stack we develop; it also powers qmux and WebTransport. Don't add or deepen dependencies on web-transport, noq, or quinn.
- `moq-cli` builds the `moq` binary and owns the CLI surface for the gateway crates.

# Producer / Consumer

A `Producer` writes and any number of `Consumer`s read, sharing state via `kio`. Clones share state, the last drop closes cleanly, and `abort(err)` closes with an error.

- A parked clone keeping something alive is a bug in the holder. A consumer never keeps its producer or parent alive.
- A track, group, or frame consumer seeing `Error::Dropped` is a bug: find the path where its producer dropped unfinished and `abort` with the real cause. Lifecycle watchers like `track::Demand` return `Dropped` after `close()` by design.

# Async

- New logic is a `poll_*(&kio::Waiter) -> Poll<...>` with an `async` wrapper generated by `#[cfg_attr(feature = "async", kio::wrapper)]`. Document what it resolves to, not how it registers.
- A library build without `async` compiles no coroutines (`just rs coroutines`).
- A `poll_*` that waits on several things in a fixed order is a `#[kio::machine]` with `wait!`. Hand-write it when a wait sits in a loop or branch, or it yields more than once.
- Libraries use `kio`, not `tokio::spawn`, `select!`, `tokio::sync`, or `pin!` inside `kio::wait`. A channel carrying a single value is a smell.
- Use `ready!(...)`, adding `?` for `Result` polls, instead of matching `Poll::Pending`.

# Conventions

- `thiserror` for libraries, `anyhow` with `.context(...)` for binaries. Don't re-export a third-party error type unless the crate wraps that dependency.
- Terminal operations consume `self`; rely on `Drop` over a `close` the user can forget.
- Typed units only (`Duration`, `moq_net::Timestamp`), never `f64` seconds or bare millis.
- Flushing, cutting, and expiry advance on max(wall clock, pts) through a timer: peer timestamps are untrusted, and a sparse track may never send another frame.
- Derive `Serialize`/`Deserialize` (with `serde_with` as needed) instead of hand-writing a second copy of the wire shape.
- Keep `mod encoder` private and re-export flat as `encode::Encoder`.
- Dependencies use `{ workspace = true }`, except internal dev-dependencies, which are path-only so releases publish.
- Newtypes and enums over untyped strings.

# Semver

- `#[non_exhaustive]` only on error enums, enums that will gain variants, and `Config`-style structs with `pub` fields.
- Append variants to the end of a public fieldless enum; inserting reorders `as` values.
- A renamed flag or env var stays as a hidden arg reported through `deprecated()` into `moq_tokio::cli::Deprecated`, which fails startup naming the replacement. Never advertise the old name.

# Features

- Defaults skip anything expensive to build or needing a system library. Add a feature only for a vendor integration or system dependency.
- A feature lives in the crate that owns the integration; dependents forward it under the same name.
- Gate the dependency, not the logic, so the logic's tests stay in the merge gate.

# Testing

- Tests are inline `#[cfg(test)] mod tests`; full Client/Server session tests go in the crate's `tests/integration/`.
- Time-dependent async tests call `tokio::time::pause()` (moq-net uses `#[kio::test]`), unless they cross real sockets; those assert lower bounds.
- Run tests through `just` (nextest), not `cargo test`. A SLOW test is a bug to fix, not a threshold to raise.
- Local checks build only the host platform; nightly covers the full feature matrix (`just rs features`) and Windows/macOS.
