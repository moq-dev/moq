# [XS] draft-ietf-moq-c4m registers the moqt claim keys

## Goal

draft-ietf-moq-c4m assigns the `moqt` claim keys in the IANA CWT Claims
registry, so a CAT can carry them without `TBD` placeholders.

This quest tracks a condition outside the repository. When it holds, delete
this quest and every `Required` entry that links it.

## Plan

As of 2026-09-30 the latest revision is -01 (2026-06-18), still using
`TBD_MOQT` and `TBD_MOQT_REVAL`, and the registry has no moqt entry. Check the
[datatracker](https://datatracker.ietf.org/doc/draft-ietf-moq-c4m/) and the
[registry](https://www.iana.org/assignments/cwt/cwt.xhtml).
