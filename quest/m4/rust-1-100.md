# [M] Build on Rust 1.100 with a crate cooldown

## Goal

The pinned build toolchain moves from 1.98.1 to 1.100
(`rust-toolchain.toml`, `flake.nix`, `nix/overlay.nix`) without slowing CI
or losing the macOS 27 dylib fix that sets its 1.98 floor. Cargo now holds
back crate versions published within the last 7 days, so a manual or
agent-run `cargo update` waits as long as Dependabot does.

The library floor (1.91) and moq-relay's (1.95) stay put.

## Plan

Decided 2026-11-12 (maintainer, /quest-plan):

- ✅ Bump the toolchain and add the cooldown in one PR (rejected: bump only;
  also raising the library floor; no quest). The cooldown setting,
  `registry.global-min-publish-age` in `.cargo/config.toml`, only works on
  Cargo 1.100. Set it to 7 days to match `.github/dependabot.yml`, and fix
  the comment there that says a manual `cargo update` is not held back.
  `CARGO_RESOLVER_INCOMPATIBLE_PUBLISH_AGE=allow` overrides it when a
  security fix can't wait.
- ✅ Keep the 1.91 library floor (rejected: raising it for `!`, `DropGuard`,
  `Box::take`, and the other new APIs). Downstream users would pay for small
  conveniences.
- ✅ No `!` in the public API. Every API that never returns already uses
  `Infallible`, which 1.100 turns into an alias for `!`. The relay's `run`
  functions do return `Ok` on graceful shutdown.
- ✅ m4 (rejected: m3, m0). The 1.98.1 pin works, and nothing waits on this.

Guidance:

- Skip 1.99.0: it miscompiled C-ABI `bool` returns on x86_64, which moq-ffi
  exports. 1.99.1 fixed that.
- Cargo 1.99 turns off incremental builds when `CI` is set, but the
  self-hosted runners keep incremental state across jobs through mbx
  (`.github/actions/rust-cache/action.yml`). Cargo 1.100 also changes where it
  puts build files, and mbx caches those files. Measure the gate's time and
  mbx cache hits before and after the bump. If either gets worse, turn
  incremental builds back on explicitly or move to an mbx version that
  handles the new layout.
- Cargo's new `unused_dependencies` lint warns by default. Fix what it finds.
  Keep cargo-shear, which also checks dev-dependencies and the lint does not.
- Rerun the macOS 27 check behind the 1.98 floor: release-profile proc macros
  and the moq-ffi and moq-gst cdylibs still load.
- Expect compile fallout from 1.100's never-type fallback change on older
  editions (moq-vaapi is edition 2021) and from the more precise `if let`
  closure captures.
- Release notes:
  [1.100.0](https://blog.rust-lang.org/2026/11/12/Rust-1.100.0/),
  [1.99.0](https://blog.rust-lang.org/2026/10/01/Rust-1.99.0/),
  [1.99.1](https://blog.rust-lang.org/2026/10/15/Rust-1.99.1/).
