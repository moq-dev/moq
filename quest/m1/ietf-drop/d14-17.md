# [L] Drop moq-transport 14-17

## Goal

`moq-net` and `@moq/net` no longer offer, accept, or contain code for
moq-transport drafts 14, 15, 16, or 17. A peer that offers only those
drafts fails negotiation loudly. `session::Limits::requests` and the relay's
`limits.*.requests` setting are gone.

## Plan

Decided 2026-10-24 with the maintainer; see the
[epic](/quest/m1/ietf-drop/README.md) for which peers this loses and why.
Draft 17 goes with 14-16 because it shares the "14-17" arms
(`SubscribeNamespaceLegacy` and others in `ietf/subscriber.rs` and
`ietf/publisher.rs`), so dropping the four together removes those arms
whole. Estimated deletion: about 2,950 production lines in Rust and 1,750
in JS, plus their tests.

Rust (`rs/moq-net`):

- `ietf::Version` loses `Draft14`..`Draft17`; `version.rs` loses the
  `moq-00` and `moqt-15`/`16`/`17` ALPNs and codes. `NEGOTIATED` becomes
  `[Lite02, Lite01]`.
- `setup.rs` keeps the codec for `LiteLegacy` only; the `Draft14`
  versions-list and `Draft15Plus` paths go.
- Delete `ietf/adapter.rs` and the `ControlStreamAdapter` session path in
  `ietf/session.rs`, the request window in `ietf/control.rs`, request IDs
  carried in responses, legacy datagrams, absolute parameter keys
  (`ietf/parameters.rs`), and the "no Track Properties" branches in
  `ietf/properties.rs`.
- Draft 17's own pieces go: the varint family that forbids 7-byte values
  (`coding/varint.rs`, `ietf/namespace.rs`), `required_request_id_delta`, and
  its `request_stream.rs` branch.
- Collapse every gate that now has one survivor. Fuzz targets
  (`fuzz.rs`) drop the four drafts.

JS (`js/net`):

- `ietf/version.ts` loses `DRAFT_07` and `DRAFT_14`..`DRAFT_17`; delete
  `ControlStreamAdapter` (`ietf/adapter.ts`) and the gated arms.
- SETUP negotiation accepts only lite-01/02. Today `acceptNegotiated`
  (`connection/accept.ts`) and `connect.ts` take any value in
  `Ietf.Version`, so a peer can select the unsupported 0xff000007 or a
  draft that Rust only negotiates by ALPN. Add a test that both sides refuse
  an IETF version over SETUP. The SETUP codec's draft-14 encoding that lite
  uses stays, named for its role.

Public API (breaking, `!`):

- `session::Limits::requests` and the relay's `--limits-client-requests`
  and `limits.*.requests` are removed (`rs/moq-relay/src/limits.rs`). They
  only sized the 14-16 request window. Migration: delete the setting; an old
  config fails loudly instead of being ignored.
  Removing it also resizes the draft-18+ request-ID history: `Spent`
  (`rs/moq-net/src/ietf/control.rs:200`) keeps every skipped peer request
  ID as a run and closes with INTERNAL_ERROR past `with_history(limits.window())`
  (`ietf/session.rs:412`, `window() = 2*(announces+requests)`), a constant
  whose only effect is a refusal (found by the 2026-10-24 pre-cut audit,
  new on main). Decide it here: replace `Spent` with a per-parity
  high-water mark (on draft 18+ each request owns its stream, and only
  `Publisher::joins` is keyed by request ID), or size it explicitly.
- `--version`/`--connect-version` stop accepting `moq-transport-14`..`17`.
  The CLI derives its names from `Version::names()`, so only examples change.
- Wire: four ALPNs and SETUP-negotiated draft-14 are no longer offered.

Tests and CI:

- The PR-gate interop runs drafts 18 and 22 instead of 14 and 22
  (`.github/workflows/interop.yml`). Nightly (`test/interop/interop.sh`) drops
  14 and 16, and `test/interop/interop.toml` drops every entry for 14 to 17,
  since the harness accepts any version listed there.
- Moxygen moves to draft 18: `test/smoke/moxygen.sh` (rewrite its pin
  comment) and `test/ietf-conformance/run.sh`. Cloudflare smoke targets
  draft 18.
- Fix the fixtures that use these drafts, such as
  `rs/moq-relay/tests/integration/cluster_unknown.rs` and
  `rs/moq-cli/src/publish.rs`.

Docs: "draft-17 and later" becomes "draft-18 and later" for Auth, Flate, and
Epoch in `drafts/draft-lcurley-moq-{auth,flate,epoch}.md` (run
`just drafts check`), `doc/draft/`, `doc/bin/relay/auth.md`,
`doc/bin/obs.md`, every `doc/lib/*/index.md`, and `py/moq-rs/README.md`.
`doc/setup/redundancy.md` pins draft 18 as the minimal epoch draft. Fix the
`moq-transport-14` example strings in `doc/lib/js/{watch,publish}.md` and
`js/{watch,publish}/README.md`, the request limit in
`doc/bin/relay/config.md`, and the supported list in
`doc/concept/standard.md`. The moq-lite draft's informational comparisons
with 14-18 stay.

Quests: rewrite each quest that `rg -l -i 'draft[- ]?1[4-7]|d1[4-7]\b|14-1[67]' quest`
lists to what remains. For example, the Moxygen smoke quest checks its
filter-type bug at draft 18, the d17 FETCH exception in pipelined requests
goes, the 14/15 and 17 families in the passthrough epic go, and the d14
audit findings go.

moq-transport compatibility between our own released and current builds is
out of scope, since they prefer moq-lite, so a released client pinned to
these drafts against a new relay is not a regression to guard.
