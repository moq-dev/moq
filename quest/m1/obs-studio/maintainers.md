# [XS] obs-studio maintainers agree to a MoQ output

## Goal

The obs-studio maintainers agree in principle to a MoQ output and service in
obs-studio itself. The maintainer does this outreach; agents may draft the
proposal but never post to obs-studio (issues, PRs, comments, forums)
without explicit approval.

This quest tracks a condition outside the repository. When it holds, delete
this quest and every `Required` entry that links it.

## Plan

To check: ask the maintainer whether obs-studio has agreed, and record any
constraints they set (dependency policy, scope, review owners) in the
[questline](/quest/m1/obs-studio/README.md) before deleting this quest. To
advance: offer the maintainer a drafted proposal covering what the output
does, how it builds, and who maintains it.
