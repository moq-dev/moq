# [S] moq-uring's tests build on macOS and Windows

## Goal

Nightly's `platform / macOS` and `platform / Windows` jobs compile again: the
23 `error[E0433]: cannot find module or crate kio` errors are gone.

## Plan

Seen in Nightly run 40885347517 (2026-10-29). moq-uring's integration tests
include `rs/moq-uring/src/transport/adapter.rs` by path
(`tests/integration/../../src/transport/adapter.rs`), and that file names
`kio`, which is not in scope for the test crate on those platforms. moq-uring
is Linux-only, so make its integration tests build to nothing off Linux, or
give the test crate what the included file needs. Prefer the first, so a
non-Linux build never compiles io_uring code.
